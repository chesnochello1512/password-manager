# Changelog

## 1.0.1 — 2026-11-21

Исправления по результатам code review.

### Безопасность

- Смена мастер-пароля сериализована с блокировкой, восстановлением и выходом из приложения.
- Во время перешифровки нельзя закрыть диалог; автоблокировка откладывается до завершения операции.
- При выходе приложение дожидается завершения фоновой операции, прежде чем закрыть БД и затереть ключ.
- Сбой после атомарной замены файла больше не маскируется сообщением «данные не изменены»: приложение сообщает, что действует новый мастер-пароль.
- Оценка стойкости ручных паролей больше не выдаёт высокую энтропию для повторов, последовательностей и популярных паролей.
- Обновлён `cryptography` до 50.0.2 (устранены известные уязвимости).

### Надёжность

- Удаление категории выполняется одной транзакцией: записи и настройки либо обновляются вместе, либо не меняются вовсе.
- Сохранение настроек и категорий работает с копией и не мутирует состояние в памяти до успешного commit.
- Добавлены fault-injection и конкурентные тесты.

### Производительность и качество

- Счётчики категорий считаются одним проходом, поиск использует кэшированный текст.
- Добавлены `ruff`, `mypy` для ядра, `pip-audit`, GitHub Actions и Windows release workflow с SHA-256.
- Добавлен бенчмарк `tools/bench_vault.py`.

### Документация

- Описаны ограничения best-effort очистки памяти, системного буфера обмена и rollback хранилища.
- Зафиксировано ограничение формата v1: служебные временные метки не входят в AAD.
